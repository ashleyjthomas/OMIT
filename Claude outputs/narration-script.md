# Narration script — disclosure ladder study

*Stimulus Set A · for approval before ElevenLabs generation · 2026-09-21*

Written to match the register of the original OMIT decks: the cause-free emotion ("feels sad today, and doesn't know why"), the animal-locomotion facts, the "How was school today?" prompt, the narrated non-disclosure, and "a better friend."

**Gender-neutral throughout.** No pronoun appears in any sentence containing two characters; "they" is used only where the protagonist is the sole referent.

**Every line below is one audio file**, named by its `line_id`. Lines marked *classmate assignment B* are the mirror-image recordings — each child hears A or B, never both.


## Framing

| line_id | text | |
|---|---|---|
| `intro_01` | Hi! Today I'm going to tell you some stories about kids and what happened at their school. |  |
| `intro_02` | After each story I'll ask you a question. There are no right or wrong answers, I just want to know what you think. |  |

## Trial 1 — SE vs HE — Casey (Morgan, Blake)

| line_id | text | |
|---|---|---|
| `T1_open` | This is Casey. I'm going to tell you a story about Casey. |  |
| `T1_est_SE` | This morning Casey felt sad, and Casey didn't know why. |  |
| `T1_est_HE` | And this afternoon Casey felt happy, and Casey didn't know why. |  |
| `T1_meet_A1` | After school, Casey saw a classmate named Morgan. Morgan said, "Hi Casey! How was school today?" | **classmate assignment A** |
| `T1_disc_A1` | Casey told Morgan about feeling sad today, but did not tell Morgan about feeling happy today. | **classmate assignment A** |
| `T1_meet_A2` | Then, Casey saw a classmate named Blake. Blake said, "Hi Casey! How was school today?" | **classmate assignment A** |
| `T1_disc_A2` | Casey told Blake about feeling happy today, but did not tell Blake about feeling sad today. | **classmate assignment A** |
| `T1_meet_B1` | After school, Casey saw a classmate named Blake. Blake said, "Hi Casey! How was school today?" | **classmate assignment B** |
| `T1_disc_B1` | Casey told Blake about feeling sad today, but did not tell Blake about feeling happy today. | **classmate assignment B** |
| `T1_meet_B2` | Then, Casey saw a classmate named Morgan. Morgan said, "Hi Casey! How was school today?" | **classmate assignment B** |
| `T1_disc_B2` | Casey told Morgan about feeling happy today, but did not tell Morgan about feeling sad today. | **classmate assignment B** |
| `T1_mc` | Which classmate did Casey tell about feeling sad today? | **memory check** |
| `T1_dv` | Who do you think is a better friend to Casey? | **PRIMARY DV** |
| `T1_cone` | Who do you think Casey would want to share an ice cream cone with? | **secondary** |
| `T1_candy` | Who do you think Casey would want to share candy with? | **secondary** |
